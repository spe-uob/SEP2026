# SEP2026
This is the repository for the 2026-7 Software Engineering Project, where we'll release the **Weekly Workbooks**.  These have the teaching information, lecture slides and tasks you'll need to complete every week.

The **Assessments folder** incudes the guide to the presentations, information about how we assess you and the Release checklist that you'll need to upload after each release (MVP, Beta and Final Releases).

**Useful things** has information that might be useful, like where you can work as a team, how to book rooms to meet clients and how to get software, tech services and hardware for your project.

The main **[SPE-UoB organisation](https://github.com/spe-uob)** contains all the student repos from the past few years, so you can look at what other students have done in SEP and see what other teams are doing this year. 

We also have the **[Knowledge hub](https://github.com/spe-uob/knowledge-hub)** with information on various topics that previous years' students have written for us, including how to do common tasks.

## Check your commits are attributed to you
**It is important that your email address is correct in the gitconfigs, so that Github can match up your commits with your account.**
 
There is more information about setting up your commit email address in [this GitHub doc](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-personal-account-on-github/managing-email-preferences/setting-your-commit-email-address)
 
You can check if your set-up is correct by trying `git config --list` and if it's not set up properly, `user.email` will be either not there or empty. Which could be fixed with 
`git config --global user.email "name@domain.example"`

If you've tried this and your commits still aren't being logged correctly, ask in the [Teams Q&A channel](https://teams.microsoft.com/l/channel/19%3A234d66b3097d4baeaf04abfdef596bc2%40thread.tacv2/Questions%20and%20Answers?groupId=843eb232-1d99-4994-9266-7ee9638bb6d7&tenantId=b2e47f30-cd7d-4a4e-a5da-b18cf1a4151b) and one of the TAs will help you.
